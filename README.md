# Rental Manager / מנהל שכירויות

A rental management application built with Python and CustomTkinter for managing rental properties, tariffs, and billing.

## Features

- Tariff Management (ניהול תעריפים)
- Apartment Management (ניהול דירות)
- Database-backed storage with SQLite
